使用聲明

DISCLAIMER

本站是一個 prompt（提示詞）整理與分享的資料庫。

將各處的提示詞集中收錄、分類編碼，並附上視覺參考，方便查找與運用。

提示詞屬於通用的文字敘述，本站僅作整理與編排，內容供學習與創作參考。

實際生成結果，請依各生圖平台的規範使用。

提示詞的命名多為方便辨識而取，未必精確；
尚未附上圖片的項目，其名稱與 prompt 的對應仍在整理中，
可能不完全一致，還請見諒。

使用教學

HOW TO USE
1基本介紹
  • 分類瀏覽：所有 prompt 都已整理成分類，並附上對應編碼
  • 快速查找：可以直接滑動瀏覽，或用關鍵字搜尋定位
  • 複製 📋：點卡片上的複製鈕，即可複製該則 prompt
  • 收藏 ☆：點收藏鈕加入收藏，之後從「收藏」分頁快速取用
  • 新增 ＋：右上角可自行填入專屬於你的提示詞（僅自己可見）
🛠️部分圖片仍在陸續補上，敬請耐心等待，會慢慢補齊。

2組合工作檯 aka 抽抽樂
  • 開啟 🧺：點右下角的籃子，即可開啟組合工作檯
  • 選分類：勾選想要的分類，涵蓋人物特徵、服飾、表情動作、場景氛圍、鏡頭、畫風版面等
  • 人物設定：可調整人數與性別，也能自行填寫每位角色的設定
  • 隨機抽一套：按下後，系統會從勾選的分類中各挑一項，湊成一整套組合
  • 複製組合：點最下方的 複製完整 prompt，即可複製整套內容
有些喜歡、有些不喜歡，需要整套重抽嗎？

不用，用這幾個功能就能局部微調：

  • 鎖定：勾選該列前面的方框，鎖住這則提示詞，下次抽取不會更動它
  • 單獨重抽：點該列後面的骰子，只重抽這一列
  • 右上角清除：想換一組不同分類時，建議先清除，避免殘留舊分類

3專屬魚魚客服
彩蛋 · EASTER EGG
  • 呼叫 ▲：點籃子上方的三角形，魚魚客服就會浮出來
  • 開始對話：接著點一下浮出的魚魚，即可打開聊天視窗
  • 提出需求：在視窗裡輸入你的問題，牠會（努力地）回應你

小提醒：
別把牠的回覆太當真——這位魚魚客服藏了不少彩蛋，
多跟牠聊幾句、東問西問，往往會有意想不到的驚喜等著你發掘。
